This is an example of some sorting algorithms, this was done as a part of my coursework in one of my CS courses.

Merge Sorts split sequentially until each element has either one or two, and sorts them, then combines them incrementally until the sorted array is returned.

Quick Sorts split arrays into higher or lower values by using a pivot (the last value in the array) and sequentially does so until the array is sorted and can be fully combined.

Radix Sorts sequentially sort each last and next last digit in arrays to fully sort the returned array.
